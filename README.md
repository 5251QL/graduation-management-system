# 毕业去向管理系统 🎓

> 一个由 AI 和人类共同完成的课程设计——人类负责提需求，AI 负责写代码，人类负责说「不对，重来」，AI 负责改。

## 🤝 分工说明

| 角色 | 负责内容 |
|------|---------|
| 🧑 人类（我） | 想需求、写需求说明书、运行 `npm start`、点头、摇头、交作业 |
| 🤖 DeepSeek | 写前端 Vue 组件、写后端 Express API、写 SQL、debug、修 bug、再修 bug、解释为什么刚才修错了 |

## 📦 技术栈

我不知道这些是干嘛的，但 AI 说用了它们：

`Vue 3` `Element Plus` `Express` `MySQL` `JWT` `bcrypt` `SheetJS` `PDFKit`

## 🚀 运行方式

```bash
npm install && cd client && npm install && cd ..
mysql -u root -p < server/init_db.sql
npm start          # 后端 :3000
cd client && npm run dev   # 前端 :5173
```
