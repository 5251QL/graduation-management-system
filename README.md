# 毕业去向管理系统 🎓

> 一个由 AI 和人类共同完成的课程设计——人类负责提需求，AI 负责写代码，人类负责说「不对，重来」，AI 负责改。

## 🎯 项目概述

一个基于 Web 的毕业去向管理系统，支持管理员批量导入学生就业数据、多维度筛选、Excel/PDF 导出、双角色权限管理。

### 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | HTML / CSS / JavaScript（原生 + Vue 3） |
| 后端 | Node.js + Express 5 |
| 数据库 | MySQL + 连接池 |
| 认证 | JWT + bcrypt 密码哈希 |
| 文件处理 | SheetJS（Excel 解析）、PDFKit（PDF 生成）、Multer（上传） |
| 接口规范 | RESTful API |

### 开发背景

本项目为课程设计任务。我主修**电子信息工程**（模电/数电/嵌入式方向），在无任何前后端开发基础的情况下，通过 **AI 辅助开发**在 **2 周内**从零完成了：

- 需求分析与文档撰写（4 份技术文档）
- 数据库建模与建库脚本编写
- 后端 15 个 RESTful API 接口设计与实现
- 前端 3 个完整页面（登录/管理端/学生端）
- 非标准化 Excel 智能解析算法
- 功能测试与 Bug 修复（28 项测试用例全部通过）

## 🚀 运行方式

```bash
npm install && cd client && npm install && cd ..
mysql -u root -p < server/init_db.sql
npm start          # 后端 :3000
cd client && npm run dev   # 前端 :5173
```
